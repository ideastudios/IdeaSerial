# 路线图 / Roadmap

## ✅ v0.2.1 已完成

- 应用内检查更新：菜单「检查更新」拉取 feed 分支 latest.json 比对版本，发现新版本弹窗提示，点击「去下载」跳转系统浏览器下载 APK

## ✅ v0.2.0 已完成

- 横屏双栏布局（左侧整栏日志 + 右侧控制面板），布局随转屏自动切换
- 转屏状态保留：串口连接、TX/RX 日志、未读角标、自动发送循环不丢失（会话层重构）
- 日志卡片内置清屏按钮与专注模式（隐藏发送区，日志占满整屏）
- 应用级全屏模式（菜单切换，边缘滑动临时唤出系统栏）+ 双击返回退出确认
- 串口 Tab 显示绑定设备名（ttyS1 / CH340 等），切换设备一目了然
- 消除横屏摄像头侧黑边（shortEdges 挖孔模式）
- 文件发送进度对话框转屏可恢复，任务与 UI 生命周期解耦
- 修复退出应用后串口不释放的问题

## ✅ v0.1.0 已完成

- USB OTG 串口支持（CH340/CH341、CP210x、FTDI、PL2303、CDC/ACM，免 root）
- 串口参数完整可配（数据位/停止位/校验/流控）
- 串口搜索增强（/dev 直扫 + 手动输入路径）
- USB 权限引导与错误分场景提示
- Material 3 + ViewBinding 现代化 UI
- RecyclerView 日志列表（批量刷新、5000 条上限）
- TX/RX 颜色区分日志
- 快捷命令库（自定义、Hex、自动换行）
- 配置存储 JSON 化（Gson）
- 高波特率性能优化（去轮询休眠、字节计数）
- 发送文件（SAF 分块发送、进度可取消）
- Android 13+ 单色主题图标

## 🔲 规划中

- 时间戳显示开关 UI（目前配置项已预留）
- 接收区搜索与过滤
- 换行符可选（CR / LF / CRLF / 无）
- 校验和 / CRC 计算与自动附加
- 数据可视化（实时波形图）
- 动态多串口（突破固定 4 路）
- TCP/UDP 网络串口
- 简单脚本 / 宏自动化
- 完整多语言支持
