# 路线图 / Roadmap

## ✅ v0.1.0 已完成

- USB OTG 串口支持（CH340/CH341、CP210x、FTDI、PL2303、CDC/ACM，免 root）
- 串口参数完整可配（数据位/停止位/校验/流控）
- 串口搜索增强（/dev 直扫 + 手动输入路径）
- USB 权限引导与错误分场景提示
- Material 3 + ViewBinding 现代化 UI
- RecyclerView 日志列表（批量刷新、5000 条上限）
- TX/RX 颜色区分日志
- 快捷命令库（自定义、Hex、自动换行）
- 配置存储 JSON 化（Gson）
- 高波特率性能优化（去轮询休眠、字节计数）
- 发送文件（SAF 分块发送、进度可取消）
- Android 13+ 单色主题图标

## 🔲 规划中

- 时间戳显示开关 UI（目前配置项已预留）
- 接收区搜索与过滤
- 换行符可选（CR / LF / CRLF / 无）
- 校验和 / CRC 计算与自动附加
- 数据可视化（实时波形图）
- 动态多串口（突破固定 4 路）
- TCP/UDP 网络串口
- 简单脚本 / 宏自动化
- 完整多语言支持

欢迎提 Issue 讨论需求优先级。
